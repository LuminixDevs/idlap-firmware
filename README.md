# idLap firmware

Official public binary distribution for **idLap — Open RC Transponder by rcmod.id**.

Download the latest firmware, follow the wiring guide, or flash directly from your browser at **https://rcmod.id/idlap**.

This repository contains firmware binaries, per-device ZIP downloads, manifests and SHA-256 checksums. Firmware source is maintained separately. No GitHub account is required to download.

`releases.json` is the public release index. Each version has its own directory. ZIP files contain the four ESP32-C3 flash parts, the profile manifest and checksums. Publishing a decoder release preserves earlier transponder releases.
